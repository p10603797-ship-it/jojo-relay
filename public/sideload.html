How this works & what you need ›

This portal uses Apple's official over-the-air (OTA) install mechanism — the same itms-services:// + manifest.plist flow used for ad-hoc and in-house app distribution. It makes distribution one tap. It does not bypass Apple's code-signing: an app will only install if it is properly signed and authorised for your device.

You need, before an install will succeed

  1. A signed .ipa, hosted over https:// with a valid certificate. Signing options:
    • Ad-hoc (paid Apple Developer, $99/yr): signed with a provisioning profile that lists your device's UDID. Installs on registered devices only.
    • Enterprise (Apple Developer Enterprise, $299/yr): in-house distribution, for your own org.
    • Your own dev builds: typically installed via Xcode/AltStore for free accounts — a free personal Apple ID can't do open OTA installs the same way.
  2. The manifest (this site generates it for you) served over https:// too — which happens automatically when you open this portal from its hosted URL.
  3. Open install links in Safari (not an in-app browser).
  4. After installing, trust the developer under Settings → General → VPN & Device Management if prompted.
If an install says "Unable to Install" or "could not be installed at this time," the .ipa is almost always not signed for this device, the URL isn't reachable over HTTPS, or the bundle id/version is wrong. That's Apple's security check — no website can get around it.

Use it like an app

Tap the Share icon in Safari → Add to Home Screen. It opens full-screen and your library is remembered on this device.
